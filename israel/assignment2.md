## List the types of CSS selectors we have;
  - Universal Selector *  
  - Element/Type Selector
  - Class Selector .  
  - ID Selector #  
  - Attribute Selector []  
  - Descendant Selector
  - Child Selector >  
  - Adjacent Sibling Selector +  
  - General Sibling Selector ~  
  - Pseudo-class Selector :  
  - Pseudo-element Selector ::  
  - Grouping Selector ,  
  - Compound Selectors

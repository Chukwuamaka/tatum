## Assignment

- Is doctype html and element or just a declaration
- What are the versions of html before html 5
- Find out other semantic element apart from strong and em and their non semantic counterpart

## 1. Is `<!DOCTYPE html>` an element or a declaration?

`<!DOCTYPE html>` is a **declaration**, not an HTML element. It tells the browser that the document uses HTML5.

## 2. HTML versions before HTML5

- HTML 1.0 — 1991
- HTML 2.0 — 1995
- HTML 3.2 — 1997
- HTML 4.0 — 1997
- HTML 4.01 — 1999

## 3. Semantic elements and their non-semantic counterparts

| Semantic Element | Non-Semantic Counterpart |
| ---------------- | ------------------------ |
| `<strong>`       | `<b>`                    |
| `<em>`           | `<i>`                    |
| `<header>`       | `<div>`                  |
| `<footer>`       | `<div>`                  |
| `<nav>`          | `<div>`                  |
| `<main>`         | `<div>`                  |
| `<section>`      | `<div>`                  |
| `<article>`      | `<div>`                  |
| `<aside>`        | `<div>`                  |
| `<figure>`       | `<div>`                  |
| `<mark>`         | `<span>`                 |
| `<time>`         | `<span>`                 |
| `<blockquote>`   | `<div>`                  |
| `<cite>`         | `<span>`                 |

`<div>` and `<span>` are common non-semantic elements because they do not describe the meaning of their content.

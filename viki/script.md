| Method | What it does | Mutates? | Return value |
|---|---|---|---|
| `trim()` | Removes surrounding whitespace | ❌ | New string |
| `split()` | Converts string → array | ❌ | Array |
| `charAt()` | Gets character at index | ❌ | String |
| `join()` | Converts array → string | ❌ | String |
| `forEach()` | Runs function on every item | ❌* | `undefined` |
| `filter()` | Selects matching items | ❌ | New array |
| `reduce()` | Combines items into one result | ❌ | Single value |
| `pop()` | Removes last array item | ✅ | Removed item |

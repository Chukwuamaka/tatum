## QUESTIONS
- Is “Doctype” an element or just a declaration?  
Doctype is strictly an declaration not a HTML element because it is a system instruction that tells the web browser which version of HTML is used in the webpage, helping the browser to display content correctly; hence, it creates no content on the webpage and so therefore is not a building block of the page layout.
- What are the various versions of HTML before HTML5?
1. HTML 1.0 released in 1993
2. HTML 2.0 released in 1995
3. HTML 3.2 released in 1997
4. HTML 4.0 released in December, 1997
5. HTML 4.01 released in 1999
6. XHTML 1.0 released in 2000
7. XHTML 1.1 released in 2001  
N/B: XHTML 2.0 was abandoned and never released
- Find out other semantic elements (along with non-semantic elements that performs the same functions)
1. “ins” and “u” - both presents the text on the webpage as underlined, but “ins” gives the semantic meaning that the text is inserted.
2. “del” and “strike” – both strikes through text/s on the webpage, but “del” gives the semantic meaning that the text is deleted content.
3. “cite” and “i” - both presents the text on the webpage as italics, but “cite” gives the semantic meaning that the text is a title of a book/work.
4. “dfn” and “span” - both presents the text on the webpage as italics, but “dfn” gives the semantic meaning that the text is the definition of a term.
5. “address” and “i” – both presents the text on the webpage as italics, but “address” gives the semantic meaning that the text is an contact (address) info.
